# Data Provenance

This repository is a lightweight benchmark/protocol release. It includes
synthetic smoke-test data, final aggregate summary tables, figure previews, and
provenance metadata. It does not vendor third-party model repositories, raw
upstream datasets, model checkpoints, or generated feature caches.

## Included Data

The GitHub release may include:

```text
examples/smoke_test/smoke_pairs.csv
results/tables/*.csv
assets/figures/*.png
public_export_manifest.json
```

These files are synthetic fixtures, final aggregate benchmark summaries,
paper-figure previews, or release manifests generated by the current study.

## Excluded Data

The release intentionally excludes:

```text
third-party repository clones
raw upstream datasets unless redistribution is verified
model checkpoints and pretrained weights
generated feature caches
local IDE files
nested .git directories
internal worklogs, roadmaps, handoffs, and simulated review notes
manuscript development history and exploratory AI-assisted figure-generation experiments
```

Examples of excluded local paths include:

```text
DeepRNA-DTI/
RNAsmol/
SMRTnet/
DeepRSMA/
BEACON_RNABenchmark/
.hf_cache/
cache/
Model/trained_weight/
checkpoint/
saved_model/
reports/
paper/
```

## Third-Party Sources

Third-party source provenance is recorded in:

```text
third_party/sources.yml
docs/release_provenance_audit.md
```

The manuscript uses or discusses resources from DeepRNA-DTI, RNAsmol/ROBIN, and
SMRTnet. These resources are referenced by upstream URL and commit instead of
being copied into the primary public repository. This keeps license and
redistribution boundaries explicit.

## Reproduction Levels

### Level 1: Smoke Test

The synthetic smoke test is fully self-contained and can be run without
upstream data:

```bash
python scripts/run_smoke_test.py --input examples/smoke_test --output reports/smoke_test
```

### Level 2: Summary Artifact Inspection

The repository includes final aggregate tables and figure previews for
inspection. These support review of the reported benchmark claims without
redistributing upstream raw resources.

### Level 3: Full Upstream Rerun

A full rerun requires obtaining upstream resources from their original sources
and respecting their licenses. Local compatibility patches or forks should be
used only when documented in `third_party/sources.yml`.
